# Reverse String

A simple C# console application that reads a string from the user and prints it in reverse order.

## Features
- Accepts user input
- Validates empty or whitespace-only input
- Reverses the entered text
- Displays both the original and reversed values

## Run the project
```bash
dotnet run --project ./ReverseString/ReverseString.csproj
```

## Example
```text
Enter the string: hello
The Original string is : hello
The Reverse string is : olleh
```
